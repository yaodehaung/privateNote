## `/sys/bus/acpi/devices` 與 `pci_link.c` 的關聯

在 `/sys/bus/acpi/devices` 中可以看到多個 `PNP0C0F` 裝置：

```text
PNP0C0F:00
PNP0C0F:01
PNP0C0F:02
PNP0C0F:03
PNP0C0F:04
PNP0C0F:05
PNP0C0F:06
PNP0C0F:07
```

`PNP0C0F` 是 ACPI 定義的 **PCI Interrupt Link Device** Hardware ID。

Linux Kernel 的：

```text
drivers/acpi/pci_link.c
```

會定義所支援的 ACPI device ID：

```c
static const struct acpi_device_id link_device_ids[] = {
    {"PNP0C0F", 0},
    {"", 0},
};
```

因此兩者的關聯可以表示為：

```text
BIOS / UEFI ACPI Tables
        │
        │ 定義 PCI Interrupt Link Device
        │ _HID = "PNP0C0F"
        ▼
Linux ACPI subsystem
        │
        │ 建立 ACPI device
        ▼
/sys/bus/acpi/devices/
        │
        ├── PNP0C0F:00
        ├── PNP0C0F:01
        ├── PNP0C0F:02
        ├── ...
        └── PNP0C0F:07
                │
                │ Hardware ID match
                ▼
drivers/acpi/pci_link.c

link_device_ids[]
        │
        └── "PNP0C0F"
                │
                ▼
        PCI Interrupt Link Driver
```

也就是說，`PNP0C0F:00` 到 `PNP0C0F:07` 這些 sysfs entry，是 Linux ACPI subsystem 從 ACPI tables 中發現的 PCI Interrupt Link Devices；而 `drivers/acpi/pci_link.c` 透過 `"PNP0C0F"` 這個 ACPI Hardware ID 辨識並處理這類裝置。

其中：

```text
PNP0C0F
│
└── ACPI Hardware ID
```

而：

```text
:00
:01
...
:07
```

是 Linux 為同一 Hardware ID 的不同 ACPI device instance 所加上的 instance 編號，因此系統中可以同時存在多個 `PNP0C0F` 裝置。
