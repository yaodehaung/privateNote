# Linux Kernel `net/` 與 Userspace CLI 對照表

Linux Kernel 的 `net/` 目錄包含主要網路子系統。Userspace 通常透過 Netlink、Generic Netlink、Socket API、D-Bus 等介面與 Kernel 溝通。

## 1. CLI 與 Kernel 對照表

| Linux Kernel | 主要 CLI | 主要功能 | 通訊介面 |
|---|---|---|---|
| `net/core/` | `ip` | `net_device`、link、namespace | `NETLINK_ROUTE` |
| `net/ipv4/` | `ip`, `ss` | IPv4、Routing、ARP、TCP/UDP | Netlink / Socket DIAG |
| `net/ipv6/` | `ip`, `ss` | IPv6、Routing、NDP、TCP/UDP | Netlink / Socket DIAG |
| `net/8021q/` | `ip` | IEEE 802.1Q / 802.1ad VLAN | `NETLINK_ROUTE` |
| `net/bridge/` | `bridge`, `ip` | Bridge、FDB、MDB、Bridge VLAN | `NETLINK_ROUTE` |
| `net/sched/` | `tc` | Qdisc、Class、Filter、Action | `NETLINK_ROUTE` |
| `net/netfilter/` | `nft` | Firewall、Filtering、NAT | `NETLINK_NETFILTER` |
| `net/ethtool/` | `ethtool` | NIC link、features、statistics | Generic Netlink / legacy ioctl |
| `net/devlink/` | `devlink` | NIC / Switch ASIC、Port、Health | Generic Netlink |
| `net/xfrm/` | `ip xfrm` | IPsec / XFRM state、policy | `NETLINK_XFRM` |
| `net/mptcp/` | `ip mptcp` | Multipath TCP | Generic Netlink |
| `net/mpls/` | `ip` | MPLS route / label | `NETLINK_ROUTE` |
| `net/dcb/` | `dcb` | Data Center Bridging | `NETLINK_ROUTE` |
| `net/bluetooth/` | `bluetoothctl`, `btmgmt`, `btmon` | Bluetooth HCI、L2CAP、SCO | D-Bus / `AF_BLUETOOTH` |
| `net/mac80211/` | `iw` | mac80211 Wi-Fi | `nl80211` |
| `net/wireless/` | `iw` | cfg80211 / Wireless configuration | `nl80211` |
| `net/rfkill/` | `rfkill` | Wi-Fi / Bluetooth RF Kill | rfkill interface |
| `net/tipc/` | `tipc` | TIPC | Generic Netlink |
| `net/batman-adv/` | `batctl` | B.A.T.M.A.N. mesh | Generic Netlink |
| `net/netlink/` | 無單一 CLI | Netlink infrastructure | Netlink |
| Socket subsystem | `ss` | TCP / UDP / Unix Socket inspection | Socket DIAG / Netlink |

# 2. `ip`

`ip` 是 Linux networking 最重要的 CLI 之一，來自 `iproute2`。

常見命令：

```bash
ip link
ip addr
ip route
ip neigh
ip rule
ip netns
```

大致架構：

```text
ip
 │
 ├── ip link
 ├── ip addr
 ├── ip route
 ├── ip neigh
 └── ip netns
       │
       ▼
 NETLINK_ROUTE
       │
       ├── net/core/
       ├── net/ipv4/
       └── net/ipv6/
```

例如：

```bash
ip link show
```

可以查看 `net_device`。

# 3. VLAN：`net/8021q/`

Linux IEEE 802.1Q / 802.1ad VLAN 的主要實作位於：

```text
net/8021q/
```

建立 VLAN interface：

```bash
sudo ip link add link eth0 name eth0.10 type vlan id 10
sudo ip link set eth0.10 up
```

架構：

```text
eth0
 │
 └── eth0.10
      VLAN ID 10
```

CLI 到 Kernel：

```text
ip link add ... type vlan
          │
          ▼
    NETLINK_ROUTE
          │
          ▼
      rtnetlink
          │
          ▼
     net/8021q/
```

主要可以研究：

```text
net/8021q/vlan.c
net/8021q/vlan_core.c
net/8021q/vlan_dev.c
net/8021q/vlan_netlink.c
```

# 4. Bridge：`net/bridge/`

Linux Layer 2 Bridge 主要使用：

```bash
ip
bridge
```

建立 Bridge：

```bash
sudo ip link add br0 type bridge
sudo ip link set br0 up
```

加入 Port：

```bash
sudo ip link set eth0 master br0
sudo ip link set eth1 master br0
```

架構：

```text
        br0
       /   \
    eth0   eth1
```

查看：

```bash
bridge link show
bridge fdb show
bridge vlan show
bridge mdb show
```

對應：

```text
bridge
   │
   ▼
NETLINK_ROUTE
   │
   ▼
net/bridge/
```

其中：

```text
bridge fdb
    ↓
net/bridge/br_fdb.c

bridge vlan
    ↓
net/bridge/br_vlan*.c
```

# 5. Traffic Control：`net/sched/`

CLI：

```bash
tc
```

主要功能：

```text
tc
├── qdisc
├── class
├── filter
└── action
```

例如查看 Qdisc：

```bash
tc qdisc show
```

增加 netem：

```bash
sudo tc qdisc add dev eth0 root netem delay 100ms
```

流程：

```text
tc
 │
 ▼
NETLINK_ROUTE
 │
 ▼
RTM_NEWQDISC
 │
 ▼
net/sched/sch_api.c
 │
 ▼
Qdisc_ops
 │
 ▼
net/sched/sch_netem.c
```

`net/sched/` 常見：

```text
sch_*.c     Qdisc
cls_*.c     Classifier
act_*.c     Action
```

例如：

```text
sch_netem.c
sch_fq.c
sch_fq_codel.c
sch_htb.c

cls_flower.c
cls_bpf.c

act_gact.c
act_mirred.c
act_bpf.c
```

# 6. Netfilter：`net/netfilter/`

主要 CLI：

```bash
nft
```

查看：

```bash
sudo nft list ruleset
```

架構：

```text
nft
 │
 ▼
NETLINK_NETFILTER
 │
 ▼
net/netfilter/
```

主要處理：

```text
Firewall
Filtering
NAT
Connection Tracking
```

舊系統也可能看到：

```text
iptables
ip6tables
ebtables
```

現代 Linux 建議優先研究 nftables。

# 7. Ethtool：`net/ethtool/`

CLI：

```bash
ethtool
```

例如：

```bash
ethtool eth0
ethtool -k eth0
ethtool -S eth0
```

架構：

```text
ethtool
   │
   ▼
Generic Netlink
   │
   ▼
net/ethtool/
   │
   ├── net_device
   ├── ethtool_ops
   └── phylib
          │
          ▼
   drivers/net/phy/
```

例如 PHY 的：

```text
Auto-Negotiation
Speed
Duplex
MDI / MDI-X
```

都可能透過 ethtool 查詢或設定。

   ▼

- Hardware resources

# 12. Socket：`ss`

CLI：

```bash
ss
```

例如：

```bash
ss -t
ss -u
ss -l
ss -tunlp
```

查看 TCP：

```bash
ss -tn
```

查看 listening socket：

```bash
ss -lntp
```

大致：

```text
ss
 │
 ▼
Socket DIAG / Netlink
 │
 ├── TCP
 ├── UDP
 └── Unix Socket
```

## 14. 建議研究順序

如果目標是研究 Linux Kernel Networking source code，可以依照：

```text
1. ip
      ↓
   NETLINK_ROUTE
      ↓
   net/core/
   net/ipv4/
   net/ipv6/

2. bridge
      ↓
   net/bridge/
      ↓
   FDB / Forwarding / VLAN

3. tc
      ↓
   net/sched/
      ↓
   Qdisc / Classifier / Action

4. nft
      ↓
   net/netfilter/
      ↓
   Firewall / NAT

5. ethtool
      ↓
   net/ethtool/
      ↓
   net_device / PHY / Driver

6. devlink
      ↓
   net/devlink/
      ↓
   Hardware Management

7. iw
      ↓
   nl80211
      ↓
   cfg80211 / mac80211

8. ss
      ↓
   Socket DIAG
      ↓
   TCP / UDP / Socket internals
```

核心 CLI 可以先記：

```text
ip        → Core / IPv4 / IPv6 / VLAN / Routing
bridge    → Bridge / FDB / MDB / Bridge VLAN
tc        → Traffic Control
nft       → Netfilter
ethtool   → NIC / PHY
devlink   → Network hardware management
iw        → Wi-Fi
ss        → TCP / UDP / Socket
btmgmt    → Bluetooth
```
