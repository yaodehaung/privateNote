# VM 專用 Linux Kernel `.config` 建立流程

**Author:** Nick Huang
**Date:** 2026-09-13
**Kernel Version:** Linux 7.3.0-rc2+
**Environment:** VMware Virtual Machine

---

## 目的

從目前正在 VM 中執行的 Linux Kernel：

```text
7.3.0-rc2+
```

取得目前 Kernel 的設定，並根據這台 VM 實際載入的 Kernel Modules 精簡 `.config`。

最後將需要的：

```text
CONFIG_xxx=m
```

全部改成：

```text
CONFIG_xxx=y
```

讓需要的 Driver 直接 Built-in 到 Kernel，最後使用產生的 `.config` Build 新 Kernel。

---

## 1. 進入 Linux Kernel Source

```bash
cd /path/to/linux
```

確認目前 Kernel：

```bash
uname -r
```

例如：

```text
7.3.0-rc2+
```

---

## 2. 複製目前 Kernel Config

將目前正在執行的 Kernel 設定複製成 Kernel Source Tree 的 `.config`：

```bash
cp /boot/config-7.3.0-rc2+ .config
```

此時：

```text
/boot/config-7.3.0-rc2+
        │
        ▼
     .config
```

---

## 3. 記錄目前載入的 Kernel Modules

將目前載入的 Module 名稱保存：

```bash
lsmod | awk 'NR>1 {print $1}' > /tmp/loaded_modules.txt
```

查看：

```bash
cat /tmp/loaded_modules.txt
```

例如：

```text
tls
qrtr
vsock_loopback
vmw_vsock_vmci_transport
vsock
snd_hda_intel
uvcvideo
videodev
e1000
```

這些代表目前 VM 正在使用或已經載入的 Kernel Modules。

---

## 4. 使用 `localmodconfig` 精簡 Kernel Config

直接執行：

```bash
make localmodconfig
```

`localmodconfig` 會參考目前系統載入的 Modules，精簡 `.config`。

```text
原始 Kernel .config
        │
        ▼
      lsmod
        │
        ▼
make localmodconfig
        │
        ▼
保留目前 VM 需要的設定
        │
        ▼
精簡後的 .config
```

---

## 5. 將 Module 改成 Built-in

`localmodconfig` 完成後，部分設定仍然可能是：

```text
CONFIG_E1000=m
CONFIG_VSOCKETS=m
CONFIG_SND_HDA_INTEL=m
```

如果希望這些功能直接編進 Kernel：

```bash
sed -i 's/^\(CONFIG_.*\)=m$/\1=y/' .config
```

例如：

```text
修改前：

CONFIG_E1000=m

修改後：

CONFIG_E1000=y
```

也就是：

```text
Module
  │
  │ CONFIG_xxx=m
  ▼
Built-in
  │
  │ CONFIG_xxx=y
  ▼
vmlinux / bzImage
```

---

## 6. 修正 Kconfig Dependency

執行：

```bash
make olddefconfig
```

讓 Kernel Kconfig 系統重新處理設定之間的 Dependency。

```text
.config
   │
   │ =m → =y
   ▼
make olddefconfig
   │
   ▼
處理 Dependency
   │
   ▼
最終 .config
```

---

## 7. 確認是否還有 Module

執行：

```bash
grep '=m$' .config
```

計算剩餘的 Module：

```bash
grep -c '=m$' .config
```

理想結果：

```text
0
```

---

## 8. 使用產生的 `.config` Build Kernel

此時：

```text
/path/to/linux/.config
```

就是接下來 Build Kernel 使用的設定檔。

開始 Build：

```bash
make -j$(nproc)
```

完成後可以安裝：

```bash
sudo make modules_install
sudo make install
```

---

# 完整操作指令

```bash
cd /path/to/linux

# 1. 確認目前 Kernel
uname -r

# 2. 使用目前 Kernel config
cp /boot/config-7.3.0-rc2+ .config

# 3. 保存目前載入中的 modules
lsmod | awk 'NR>1 {print $1}' > /tmp/loaded_modules.txt

# 查看目前 modules
cat /tmp/loaded_modules.txt

# 4. 根據目前 VM 使用的 modules 精簡 config
make localmodconfig

# 5. 將剩餘 modules 全部改成 built-in
sed -i 's/^\(CONFIG_.*\)=m$/\1=y/' .config

# 6. 處理 Kconfig dependency
make olddefconfig

# 7. 確認是否還存在 CONFIG_xxx=m
grep '=m$' .config
grep -c '=m$' .config

# 8. Build Kernel
make -j$(nproc)
```

# 整體流程

```text
/boot/config-7.3.0-rc2+
          │
          ▼
       .config
          │
          ▼
         lsmod
          │
          ▼
   make localmodconfig
          │
          ▼
  保留目前 VM 需要的功能
          │
          ▼
     CONFIG_xxx=m
          │
          │ sed
          ▼
     CONFIG_xxx=y
          │
          ▼
   make olddefconfig
          │
          ▼
    最終 .config
          │
          ▼
    make -j$(nproc)
          │
          ▼
   VM 專用 Linux Kernel
```

---

# 注意：這份 `.config` 主要只能用在目前 VM

`make localmodconfig` 是根據目前系統載入的 Kernel Modules 進行精簡。

如果目前環境是 VMware：

```text
VMware VM
   │
   ├── VMware virtual hardware
   ├── E1000
   ├── VMware VMCI
   ├── VMware VSOCK
   ├── Virtual USB
   ├── Virtual SATA
   └── Virtual display
```

其他沒有使用到的硬體 Driver 可能會被關閉，例如：

```text
Intel Wi-Fi
Broadcom Wi-Fi
Realtek NIC
Intel GPU
AMD GPU
Bluetooth
其他實體 Storage Controller
其他實體 USB Controller
```

因此這份 `.config` 適合目前 VM，但不保證能直接使用在其他 VM 或實體機器。

# 不建議的操作順序

不要先執行：

```bash
sed -i 's/^\(CONFIG_.*\)=m$/# \1 is not set/' .config
```

再執行：

```bash
make localmodconfig
```

因為這會先把所有：

```text
CONFIG_xxx=m
```

變成：

```text
# CONFIG_xxx is not set
```

等於先把原本的 Module 設定全部關掉。

正確順序：

```text
原始 Kernel Config
        │
        ▼
make localmodconfig
        │
        ▼
保留 VM 需要的 Modules
        │
        ▼
      =m → =y
        │
        ▼
make olddefconfig
        │
        ▼
最終 .config
```

最終簡化成：

```bash
cp /boot/config-7.3.0-rc2+ .config

make localmodconfig

sed -i 's/^\(CONFIG_.*\)=m$/\1=y/' .config

make olddefconfig

make -j$(nproc)
```
