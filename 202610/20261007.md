# Linux Kernel `subsys_initcall`

## 1. `subsys_initcall` 是什麼？

`subsys_initcall()` 是 Linux Kernel 的 **Initcall Level 4**。

主要用於初始化 Linux Kernel 的各種 **subsystem（子系統）**。

定義位於：

```text
include/linux/init.h
```

定義：

```c
#define subsys_initcall(fn) \
        __define_initcall(fn, 4)

#define subsys_initcall_sync(fn) \
        __define_initcall(fn, 4s)
```

因此：

```text
subsys_initcall
        ↓
initcall level 4
```

---

## 2. Linux Kernel Initcall 順序

Linux Kernel 啟動時會按照不同 initcall level 執行初始化函式：

| Level | Macro | 用途 |
|---:|---|---|
| 0 | `pure_initcall()` | 最早期初始化 |
| 1 | `core_initcall()` | Kernel core |
| 2 | `postcore_initcall()` | Core 之後 |
| 3 | `arch_initcall()` | Architecture |
| **4** | **`subsys_initcall()`** | **Subsystem** |
| 5 | `fs_initcall()` | Filesystem |
| 6 | `device_initcall()` | Device / Driver |
| 7 | `late_initcall()` | 最後階段 |

流程：

```text
pure_initcall
      ↓
core_initcall
      ↓
postcore_initcall
      ↓
arch_initcall
      ↓
subsys_initcall       ← Level 4
      ↓
fs_initcall
      ↓
device_initcall
      ↓
late_initcall
```

## 3. `subsys_initcall()` 有哪些？

Kernel 中很多 subsystem 都會使用 `subsys_initcall()`。

例如：

```text
kernel/
mm/
security/
lib/
drivers/
net/
...
```

常見例子：

```c
subsys_initcall(init_module_sysctl);

subsys_initcall(proc_schedstat_init);

subsys_initcall(user_namespace_sysctl_init);

subsys_initcall(crash_save_vmcoreinfo_init);

subsys_initcall(init_mm_sysctl);

subsys_initcall(security_initcall_subsys);

subsys_initcall(sys_info_sysctl_init);

subsys_initcall(counter_init);
```

---

## 4. MM 的例子

例如：

```text
mm/memory.c
```

有：

```c
static int __init init_mm_sysctl(void)
{
        register_sysctl_init("kernel", mmu_sysctl_table);

        return 0;
}

subsys_initcall(init_mm_sysctl);
```

表示：

```text
Kernel boot
    ↓
Initcall Level 4
    ↓
init_mm_sysctl()
    ↓
register_sysctl_init()
    ↓
註冊 MM 相關 sysctl
```

---

## 5. Security / LSM 的例子

例如：

```text
security/lsm_init.c
```

有：

```c
static int __init security_initcall_subsys(void)
{
        return lsm_initcall(subsys);
}

subsys_initcall(security_initcall_subsys);
```

流程：

```text
subsys_initcall
        ↓
security_initcall_subsys()
        ↓
lsm_initcall(subsys)
        ↓
初始化 LSM subsystem
```

LSM 包含：

```text
SELinux
AppArmor
Landlock
Smack
TOMOYO
IPE
...
```

## 6. 如何找 Kernel 裡所有 `subsys_initcall`

在 Linux Kernel source：

```bash
cd /mnt/nvme/linux

git grep "subsys_initcall("
```

或：

```bash
grep -R "subsys_initcall(" -n .
```

### 只找 MM

```bash
git grep "subsys_initcall(" -- mm/
```

### 只找 NET

```bash
git grep "subsys_initcall(" -- net/
```

### 只找 Kernel

```bash
git grep "subsys_initcall(" -- kernel/
```

### 同時找 `subsys_initcall_sync`

```bash
git grep -E "subsys_initcall(_sync)?\("
```

## 7. `subsys_initcall_sync`

除了：

```c
subsys_initcall(foo);
```

還有：

```c
subsys_initcall_sync(foo);
```

兩者都是 Level 4，但 linker section 不同：

```text
subsys_initcall
      ↓
.initcall4.init

subsys_initcall_sync
      ↓
.initcall4s.init
```

因此同一 level 中會有更細的排序。

## 8. Kernel Boot 如何執行它？

大致流程：

```text
start_kernel()
      ↓
rest_init()
      ↓
kernel_init()
      ↓
kernel_init_freeable()
      ↓
do_basic_setup()
      ↓
do_initcalls()
      ↓
do_initcall_level()
      ↓
Level 0
Level 1
Level 2
Level 3
Level 4 ← subsys_initcall
Level 5
Level 6
Level 7
```

核心程式主要可以從：

```text
init/main.c
```

開始追。

重點函式：

```c
do_initcalls();
```

接著：

```c
do_initcall_level(level);
```

概念上：

```text
do_initcalls()
      │
      ├── Level 0
      │
      ├── Level 1
      │
      ├── Level 2
      │
      ├── Level 3
      │
      ├── Level 4
      │      ↓
      │   subsys_initcall()
      │
      ├── Level 5
      ├── Level 6
      └── Level 7
```

## 9. Built-in 與 Module 的差異

如果程式：

```text
CONFIG_XXX=y
```

代表 built-in。

這時：

```c
subsys_initcall(foo);
```

會按照 Kernel initcall level 執行：

```text
Level 4
    ↓
foo()
```

但如果：

```text
CONFIG_XXX=m
```

編譯成 module：

```text
xxx.ko
```

載入：

```bash
modprobe xxx
```

此時初始化是在 **module load** 時執行，而不是 Kernel boot 的 Level 4。

所以研究 initcall 時一定要注意：

```text
=y
```

還是：

```text
=m
```

# Summary

`subsys_initcall()`：

```text
subsys_initcall(fn)
        ↓
__define_initcall(fn, 4)
        ↓
Initcall Level 4
        ↓
Kernel subsystem initialization
```

整體順序：

```text
0  pure
      ↓
1  core
      ↓
2  postcore
      ↓
3  arch
      ↓
4  subsys       ← subsys_initcall
      ↓
5  fs
      ↓
6  device
      ↓
7  late
```

如果要研究實際執行流程，主要看：

```text
include/linux/init.h
        ↓
init/main.c
        ↓
do_initcalls()
        ↓
do_initcall_level()
```
