# Linux Kernel UAPI Header

**Author:** Nick Huang
**Date:** 2026-09-13

## UAPI 是什麼？

`UAPI` 全名是：

```text
User-space API
```

Linux Kernel 使用 `uapi/` 目錄來區分：

* Kernel 內部使用的 Header
* 可以提供給 User Space 使用的 Header

例如：

```text
arch/x86/include/
├── asm/
│   └── setup.h
│       ↑ Kernel internal header
│
└── uapi/
    └── asm/
        └── boot.h
            ↑ 可以提供給 User Space
```

---

## `uapi/` 不會出現在最終 Include Path

`uapi` 是 Linux Kernel Source Tree 裡面的分類目錄。

例如 Source Tree：

```text
arch/x86/include/uapi/asm/boot.h
```

執行：

```bash
make ARCH=x86 headers_install
```

之後會安裝成：

```text
usr/include/asm/boot.h
```

所以 User Space 程式使用：

```c
#include <asm/boot.h>
```

而不是：

```c
#include <uapi/asm/boot.h>
```

---

## Header Install 流程

```text
Kernel Source Tree

arch/x86/include/uapi/asm/
           │
           │ make headers_install
           ▼
       usr/include/asm/
```

例如：

```text
arch/x86/include/uapi/asm/boot.h
                │
                ▼
        usr/include/asm/boot.h
```

另一個例子：

```text
include/uapi/linux/if.h
          │
          ▼
usr/include/linux/if.h
```

User Space 最後使用：

```c
#include <linux/if.h>
```

---

## Kernel Header 與 UAPI Header

```text
Linux Kernel Source
        │
        ├── include/
        │      ↑
        │      Kernel internal headers
        │
        └── include/uapi/
               ↑
               User Space API headers
```

Architecture-specific header 也是相同概念：

```text
arch/x86/include/
        │
        ├── asm/
        │    ↑
        │    x86 Kernel internal headers
        │
        └── uapi/asm/
             ↑
             x86 User Space API headers
```

---

## `asm-generic` 是什麼？

`asm-generic` 是 Linux 提供的 Architecture Generic Header。

例如：

```text
include/uapi/asm-generic/setup.h
```

其中：

```text
uapi
 ↓
給 User Space 的 API

asm-generic
 ↓
Architecture 通用版本
```

所以：

> `include/uapi/asm-generic/setup.h` 是 Linux 提供的 Architecture Generic UAPI `setup.h`。

---

## 最簡單記法

```text
arch/x86/include/asm/
        ↓
x86 Kernel 自己使用

arch/x86/include/uapi/asm/
        ↓
x86 提供給 User Space

include/uapi/asm-generic/
        ↓
Architecture 通用的 User Space API
```

`uapi/` 是 **Linux Kernel Source Tree 中用來分類 User Space API Header 的目錄**。

經過：

```bash
make headers_install
```

之後：

```text
Source:
arc
```
